개인정보처리방침

최종 수정: 2026-08-10 (v0.6.1: 우회 엔진 및 브라우저 호환성 강화)

Right-click on Web 확장 프로그램(이하 "본 확장")은 사용자의 개인정보를 수집·저장·가공·전송하지 않습니다. 본 정책은 사용자가 본 확장을 설치·사용하는 동안 어떤 데이터가 어디에 저장되고 어떻게 처리되는지를 명시합니다.

1. 수집하는 정보

본 확장은 다음 정보를 수집하지 않습니다:

  • 브라우징 기록, 방문한 웹사이트의 페이지 내용, 마우스/키보드 입력
  • 쿠키, 로컬 스토리지(LocalStorage), IndexedDB 등 웹사이트 데이터
  • 위치, 기기 식별자, IP 주소, 광고 식별자
  • 사용자 인증 정보, 결제 정보, 개인정보

2. 저장하는 데이터

본 확장이 저장하는 데이터는 사용자가 직접 구성한 설정 값뿐이며, 페이지 내용·텍스트 선택·복사 내용 등은 절대 저장하지 않습니다.

  • 전역 ON/OFF 플래그 — 단일 boolean (기본값 true)
  • 도메인별 설정 목록 — 사용자가 팝업, 설정 화면, 또는 컨텍스트 메뉴에서 등록한 hostname 문자열과 각 도메인의 ON/OFF·완화 모드(Lite/Ultimate)
  • 세션 임시 활성화 — 해당 hostname에 한해 이번 세션 동안 ON으로 강제 (브라우저 종료 시 자동 소멸, Firefox MV3는 비활성)

3. 저장 위치

v0.4.0부터 설정 데이터는 다음 두 영역에 저장됩니다:

  • chrome.storage.local — 현재 기기에 로컬 저장. 항상 사용.
  • chrome.storage.sync (Chrome Sync) — 사용자 Google 계정에 동기화하여 동일 Chrome 계정으로 로그인한 다른 기기에서도 동일 설정을 유지. Chrome Sync가 활성화된 경우에만 동작합니다.

동기화되는 정보는 사용자가 직접 구성한 설정값(전역 boolean + 도메인 목록)뿐이며, 어떤 사용자 행동·페이지 내용·텍스트 입력·방문 기록도 포함되지 않습니다.

4. 외부 전송

본 확장은 자체 원격 서버로 데이터를 전송하지 않습니다. 네트워크 요청, 텔레메트리, 광고 SDK, 분석 도구, 외부 코드 로딩이 전혀 포함되어 있지 않습니다.

단, chrome.storage.sync 사용 시 설정 데이터는 Google의 Chrome Sync 인프라를 통해 Google 계정에 저장되며, 다른 로그인된 기기로 전파됩니다. 이는 Chrome 플랫폼이 제공하는 표준 동기화 메커니즘이며 본 확장이 별도로 전송하는 것은 아닙니다.

5. 권한 안내

본 확장은 다음 Chrome 권한을 사용합니다:

  • storage — 설정 저장 및 동기화
  • activeTab — 팝업에서 현재 탭의 hostname 조회 (도메인별 설정 UI용)
  • contextMenus — 확장 아이콘의 우클릭 메뉴에서 전역 토글·사이드 패널 진입·전체 설정 화면 진입을 제공
  • sidePanel — Chrome 사이드 패널에서 저장된 사이트 설정 관리
  • <all_urls> (호스트 권한) — 모든 웹페이지에서 우클릭/선택/복사 차단 스크립트를 완화하기 위함. 페이지 내용을 수집하거나 저장하는 데 사용되지 않습니다.

6. 동기화 비활성화

동기화를 비활성화하려면 chrome://settings/syncSetup에서 "확장 프로그램" 항목을 끄거나, Chrome Sync 자체를 비활성화할 수 있습니다. 동기화가 비활성화된 경우 설정은 chrome.storage.local에만 저장되며 다른 기기로 전파되지 않습니다.

동기화 quota (Chrome 정책상 100KB / 기기당)가 초과된 경우 본 확장은 자동으로 chrome.storage.local에 데이터를 저장하며, 이는 사용자에게 팝업의 "동기화 사용량" 표시로 안내됩니다.
