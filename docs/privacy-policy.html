개인정보처리방침

최종 수정: 2026-07-31

Right-click on Web 확장 프로그램(이하 "본 확장")은 사용자의 개인정보를 수집·저장·가공·전송하지 않습니다. 본 정책은 사용자가 본 확장을 설치·사용하는 동안 어떤 데이터도 다루지 않음을 명시합니다.

1. 수집하는 정보

본 확장은 다음 정보를 수집하지 않습니다:

  • 브라우징 기록, 방문한 웹사이트 주소(URL)
  • 입력한 텍스트, 비밀번호, 결제 정보 등 사용자 입력 내용
  • 쿠키, 로컬 스토리지(LocalStorage) 등 웹사이트 데이터
  • 위치, 기기 식별자, 개인 식별 정보

2. 데이터 저장

본 확장이 저장하는 유일한 데이터는 확장의 ON/OFF 토글 설정 값 하나뿐이며, 이 값은 브라우저의 chrome.storage.local에만 로컬로 저장됩니다. 이 값은 사용자 기기 밖으로 전송되지 않으며, 확장을 제거하면 함께 삭제됩니다.

3. 외부 전송

본 확장은 어떠한 원격 서버로도 데이터를 전송하지 않습니다. 네트워크 요청, 텔레메트리, 광고 SDK, 분석 도구, 외부 코드 로딩이 전혀 포함되어 있지 않습니다.

4. 권한 안내

본 확장은 모든 웹페이지에서 우클릭/선택/복사 차단 스크립트를 완화하기 위해 <all_urls> 호스트 권한을 사용합니다. 이 권한은 차단 요소를 실시간 감지·완화하는 기능을 위해서만 사용되며, 페이지 내용을 수집하거나 저장하는 데 사용되지 않습니다.

5. 문의
