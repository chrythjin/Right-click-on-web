개인정보처리방침

최종 수정: 2026-08-15 (v0.10.0: 이미지 OCR, 선택형 로컬 기록, 마지막 영역 반복 계약 반영)

Right-click on Web 확장 프로그램(이하 "본 확장")은 막힌 웹 텍스트를 복구하고 선택할 수 없는 화면 텍스트를 기기 내 OCR로 추출합니다. 본 정책은 사용자가 본 확장을 설치·사용하는 동안 어떤 데이터가 어디에 저장되고 어떻게 처리되는지를 명시합니다.

1. 수집하는 정보

본 확장은 다음 정보를 개발자 또는 제3자가 외부로 수집·전송하지 않습니다:

  • 브라우징 기록, URL 경로·쿼리, 방문한 웹사이트의 페이지 내용, 마우스/키보드 입력
  • 쿠키, 로컬 스토리지(LocalStorage), IndexedDB 등 웹사이트 데이터
  • 위치, 기기 식별자, IP 주소, 광고 식별자
  • 사용자 인증 정보, 결제 정보, 개인정보

2. OCR 처리와 저장 데이터

OCR을 요청하면 현재 보이는 탭의 캡처 픽셀은 로컬 OCR 처리 중에만 메모리에 일시적으로 존재합니다. 캡처 이미지·픽셀은 저장하거나 전송하지 않으며, OCR에는 원격 서비스나 클라우드 OCR을 사용하지 않습니다.

  • 전역 ON/OFF 플래그 — 단일 boolean (기본값 true)
  • 도메인별 설정 목록 — 사용자가 팝업, 설정 화면, 또는 컨텍스트 메뉴에서 등록한 hostname 문자열과 각 도메인의 ON/OFF·완화 모드·기능 프로필
  • 세션 임시 활성화 — 해당 hostname에 한해 이번 세션 동안 ON으로 강제 (브라우저 종료 시 자동 소멸, Firefox MV3는 비활성)
  • OCR 기록 — 기본값은 OFF입니다. 사용자가 명시적으로 켠 경우에만 최종 OCR 텍스트와 허용된 제한 메타데이터(항목 ID, hostname, 저장 시각)를 현재 기기의 chrome.storage.local에 저장합니다. 기록은 최신순 최대 20개, 최대 30일, 총 최대 64 KiB로 제한되며 사용자가 개별·전체 삭제하거나 기록을 끄고 삭제할 수 있습니다.
  • 마지막 영역 반복 상태 — chrome.storage.session에 이번 브라우저 세션 동안만 tab ID, hostname, viewport, 영역 geometry, DPR, source, 시각을 저장합니다. 이전 이미지 바이트나 OCR 텍스트는 포함하지 않으며, 반복 요청은 저장된 조건을 검증한 뒤 현재 화면을 새로 캡처합니다.

OCR 기록 외에는 OCR 최종 텍스트를 영구 저장하지 않습니다. OCR 기록은 Chrome Sync에 포함되지 않고 다른 기기로 동기화되지 않습니다.

3. 저장 위치

설정 및 세션 데이터는 다음 세 영역에 저장됩니다:

  • chrome.storage.local — 현재 기기에 설정을 저장하고, 사용자가 선택한 경우에만 OCR 기록을 저장합니다.
  • chrome.storage.sync (Chrome Sync) — 사용자 Google 계정에 동기화하여 동일 Chrome 계정으로 로그인한 다른 기기에서도 설정을 유지합니다. Chrome Sync가 활성화된 경우에만 동작하며 OCR 기록은 포함하지 않습니다.
  • chrome.storage.session — 세션 임시 활성화, 최신 OCR 상태 및 마지막 영역 반복에 필요한 제한 메타데이터를 브라우저 세션 동안만 보관합니다.

동기화되는 정보는 사용자가 직접 구성한 설정값뿐이며, OCR 기록·화면 캡처·페이지 내용·텍스트 입력·방문 기록은 포함되지 않습니다.

4. 외부 전송

본 확장은 자체 원격 서버로 데이터를 전송하지 않습니다. 화면 캡처·OCR 텍스트를 업로드하지 않으며, 네트워크 요청, 텔레메트리, 광고 SDK, 분석 도구, 원격 코드 로딩, 클라우드 OCR이 전혀 포함되어 있지 않습니다.

단, chrome.storage.sync 사용 시 설정 데이터는 Google의 Chrome Sync 인프라를 통해 Google 계정에 저장되며, 다른 로그인된 기기로 전파됩니다. 이는 Chrome 플랫폼이 제공하는 표준 동기화 메커니즘이며 본 확장이 별도로 전송하는 것은 아닙니다.

5. 권한 안내

본 확장은 다음 Chrome 권한을 사용합니다:

  • storage — 설정, 선택형 로컬 OCR 기록, 세션 상태를 저장
  • activeTab — 사용자가 OCR 또는 현재 사이트 제어를 요청한 활성 탭의 hostname·가시 영역을 확인하고 화면을 캡처
  • contextMenus — 확장 아이콘과 이미지의 사용자 요청 메뉴를 제공
  • sidePanel — Chrome 사이드 패널에서 설정·OCR 결과·선택형 기록을 관리
  • offscreen — 확장 프로그램 내부 오프스크린 문서에서 로컬 WASM OCR을 실행
  • <all_urls> (호스트 권한) — 모든 웹페이지에서 차단 완화와 사용자가 요청한 이미지 OCR 좌표 확인을 수행. 페이지 내용을 수집하거나 저장하는 데 사용하지 않습니다.

6. 동기화 비활성화

동기화를 비활성화하려면 chrome://settings/syncSetup에서 "확장 프로그램" 항목을 끄거나, Chrome Sync 자체를 비활성화할 수 있습니다. 동기화가 비활성화된 경우 설정은 chrome.storage.local에만 저장되며 다른 기기로 전파되지 않습니다.

동기화 quota (Chrome 정책상 100KB / 기기당)가 초과된 경우 본 확장은 자동으로 chrome.storage.local에 데이터를 저장하며, 이는 사용자에게 팝업의 "동기화 사용량" 표시로 안내됩니다.
