# 2026-08-12 v0.8.0 로컬 WASM OCR 텍스트 추출 엔진 탑재

## 작업 개요

- **버전**: `0.8.0` (이전 버전: `0.7.0`)
- **목표**: 벤치마킹 타겟(Text From PRO & 우클릭 차단 종결자) 분석을 기반으로, DOM 텍스트 차단 해제에서 나아가 이미지, Canvas, DRM이 걸리지 않은 그래픽 영역의 텍스트를 100% 로컬 WASM OCR(Tesseract.js)로 추출하여 클립보드에 복사하는 엔진 구현.
- **배포 아티팩트**: `right-click-on-web-v0.8.0.zip` (6.1MB)

---

## 주요 구현 내역

### 1. 화면 크롭 오버레이 (`crop-overlay.js` & `crop-overlay.css`)
- 탑 레벨 프레임 전용 주입 (`all_frames: false`).
- 마우스 드래그를 통한 자유 사각형 영역 선택 (Crop Box).
- 십자선 커서, 골드/레드 모터스포츠 프리미엄 테마.
- `Esc` 키 또는 마우스 우클릭 시 즉시 취소.
- 로딩 스피너 및 클립보드 복사 결과 토스트 UI 안내.

### 2. 오프스크린 로컬 OCR 엔진 (`offscreen.html` & `offscreen.js`)
- `chrome.offscreen` API를 활용하여 Service Worker 환경의 DOM/Worker 제약 극복.
- Canvas 2D 컨텍스트 기반 캡처 이미지 크롭 처리 (`devicePixelRatio` 완벽 보정).
- Tesseract.js v5.1.1 WASM 코어 구동 (SIMD 최적화 및 일반 LSTM fallback 지원).
- 한국어(`kor`) 및 영어(`eng`) 오프라인 학습 데이터 로컬 번들링 (`langs/`).
- `workerBlobURL: false` 및 `chrome.runtime.getURL()` 기반 MV3 CSP 완전 준수.

### 3. 백그라운드 서비스 워커 브리지 (`background.js`)
- `chrome.tabs.captureVisibleTab`을 호출하여 활성 탭 화면 캡처.
- `ensureOffscreenDocument()` 싱글톤 관리로 오프스크린 문서 재사용 및 초기화.
- 브라우저 액션 우클릭 컨텍스트 메뉴에 `📷 화면 영역 텍스트 추출 (OCR)` 등록.
- 단축키 커맨드 `trigger-ocr` (`Alt+Shift+S` / `Cmd+Shift+S`) 리스너 등록.

### 4. 팝업 UI & 수동 QA 하니스
- `popup.html` & `popup.js`: OCR 캡처 버튼 및 단축키 안내 추가, Firefox 등 미지원 브라우저 방어 분기.
- `tests/manual/blocked-page.html`: **시나리오 15** (그래픽 Canvas 텍스트 OCR 복사 검증) 추가.
