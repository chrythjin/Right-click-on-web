## 사용자 변경 보호 경계

최초 관찰 시 아래 항목은 이미 dirty 상태였다. 모두 선행 사용자 변경으로
취급하며 reset, checkout, clean, 삭제, 덮어쓰기 또는 부분 되돌리기를 금지한다.

- 수정: `content.js`, `crop-overlay.js`, `offscreen.js`, `popup.js`
- 수정: `docs/INDEX.md`, `right-click-on-web-v0.8.0.zip`
- 미추적: `docs/sessions/20260813_103000_v0.8.0-release-hardening.md`

이번 작업은 제품 JS/CSS/HTML/manifest와 ZIP을 수정하지 않았다. 기존 미추적
세션 문서는 요청된 보고서 경로이므로 원문 내용을 보존하면서 기준선 정보를
추가했다. v0.9 작업 전에는 위 네 소스 파일의 diff가 그대로 존재하는지 다시
확인해야 하며, ZIP의 변경 여부를 소스 변경 여부로 대신 판단해서는 안 된다.

## Manifest 및 패키지 경계

- `manifest.json`은 Git 기준선과 동일하며 버전은 `0.8.0`이다.
- content script 순서는 MAIN `content-main.js`가 첫 항목이고, 그 뒤에
  ISOLATED `shared.js` + `content.js`, 마지막에 top-frame 전용
  `crop-overlay.js`가 온다. v0.9에서도 이 순서를 유지한다.
- 현재 ZIP은 존재하며 크기 `6,151,999` bytes, SHA-256은
  `8B8FFA2421D60D3CDD2E00AD3E6F665F8FBE8845BBCB22B46ADECDA4C9B3B0E4`이다.
- ZIP에는 23개 파일이 있다: 루트 제품 파일 15개, `icons/` 2개,
  `langs/` 2개, `lib/` 4개다. 문서, 테스트, 저장소 메타데이터는 없다.
- ZIP의 23개 파일을 같은 경로의 현재 소스와 SHA-256으로 대조한 결과
  누락 또는 내용 불일치는 0건이었다. 이는 패키지 관찰 결과일 뿐이며,
  정본 우선순위를 ZIP으로 바꾸지 않는다.
