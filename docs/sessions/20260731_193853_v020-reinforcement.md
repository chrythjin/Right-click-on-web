## 1. content-main.js (신규)

페이지 자신의 JS 컨텍스트(`world: "MAIN"`)에서 `document_start`로 실행되는 프로토타입 패처.

**차단 리스트 (축소됨)**: `contextmenu`, `selectstart`, `copy`, `cut`, `paste`, `dragstart`. 나머지(`dragover`, `drop`, `mousedown`, `mouseup`, `touchstart`, `touchend`, `touchmove`)는 ISOLATED world의 capture 단계 인터셉터가 담당 (편집 가능 요소 가드 유지).

**패치 1 — `EventTarget.prototype.addEventListener`**
- 차단 이벤트 타입에 대해 페이지의 핸들러를 `sentinelListener`(no-op)로 대체 등록.
- silent return이 아닌 no-op 등록인 이유: AbortSignal 기반 등록(`{signal}` 옵션)에서 `removeEventListener`/`controller.abort()` 호출 시 명세 계약 보존.
- `String(type)` 정규화로 `new String('contextmenu')` 우회 차단. 일반 객체의 커스텀 `toString`은 통과시켜 spec TypeError 보존.

**패치 2 — `Element.prototype.attachShadow`**
- `mode: 'closed'` 호출을 `Object.create(init)` + `mode` 오버라이드로 `mode: 'open'` 변환.
- `Object.create`로 상속/non-enumerable 사전 멤버 보존.

**토글 OFF 한계 명시**: `document_start`에 적용된 패치는 페이지 수명 동안 유지됨. README "토글 OFF 동작 범위" 절 추가.

## 2. content.js — ISOLATED world 보강

**신규 헬퍼**:
- `clearLockedIdlAttribute(element, attribute)` — `Object.defineProperty(..., {configurable:false})`로 잠긴 IDL 직접 할당(`el.oncontextmenu = fn`)을 해제. property-by-property 복사로 accessor 디스크립터 보존, getter-only 케이스는 getter를 `() => null`로 오버라이드.
- `discoverShadowHosts(root)` — `TreeWalker(NodeFilter.SHOW_ELEMENT)`로 shadow host만 골라내기. `querySelectorAll('*')` 대비 정적 NodeList 미생성.

**메모리 누수 수정**: `MutationObserver` 콜백에서 observed target이 disconnected되면 observer를 disconnect + `shadowObservers` 배열에서 제거. WeakSet alone으로는 누수 차단 불가 (배열의 strong ref가 observer 유지)였던 문제 해결.

**`enableUnlocker` 가드 통합**: `isActive` 플래그 도입. `disableUnlocker`가 일부에서 throw해도 재호출 시 중복 타이머/observer 누적을 방지.

**주기 재스캔 idle 스케줄링**: `requestIdleCallback` 우선, fallback `setTimeout(1000)`. `{timeout: 5000}` 옵션 명시.

**`isConnected` 가드**: 콜백에서 detached 요소 subtree 재순회 방지.

## 4. tests/manual/blocked-page.html

신규 섹션 3개:

**섹션 6 — 사후 등록 리스너 차단**
- "사후 차단 리스너 등록" 버튼 → `addEventListener('contextmenu', ...)` 등록
- capture 단계 검증 리스너가 `queueMicrotask`로 bubble 단계 후 판정 → 깜빡임 없는 명시적 신호
- "컨텍스트 메뉴 정상 / 무력화됨" vs "사후 리스너가 preventDefault 호출함" 시각화
- 핸들러 참조 보존으로 재등록 가능

**섹션 7 — 주기적 재바인딩**
- "주기적 재바인딩 시작/중지" 버튼
- `hasAttribute` 가드로 race 회피 (extension이 제거한 속성만 다시 부착)
- `visibilitychange` 핸들러: 백그라운드 진입 시 일시 중지, 복귀 시 재개
- `userStopped` 플래그로 사용자 명시적 중지 의도와 가시성 자동 재개 구분
- `pagehide`에서 `visibilitychange` 리스너도 정리

**섹션 8 — Closed Shadow DOM 강제 변환**
- `<closed-shadow-host>` 커스텀 요소가 `attachShadow({mode:'closed'})` + 내부에 인라인 `on*` + `addEventListener`로 차단
- 버튼 클릭 후 `host.shadowRoot !== null` 검증으로 MAIN 패치의 변환 성공 여부 명시적 확인

`.closedShadowHost` CSS 클래스 추가 (인라인 스타일 일관성).

## 한계 / 미해결

- **MAIN world 패치의 toggle-OFF 한계**: `document_start`에 적용된 프로토타입 대체는 페이지 수명 동안 유지. 동기 storage read 부재로 조건부 설치 불가. README에 명시.
- **`clearLockedIdlAttribute` 무통보 실패**: silent catch는 defensive하지만 회귀 감지 어려움. 카운터 노출 안 함.
- **Closed Shadow DOM — 봉인 후**: 이미 외부 코드에서 봉인된 root는 사후 접근 불가.
