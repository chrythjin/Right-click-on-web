# Wave 1.6 팝업 리플로우 (200% 줌 및 좁은 뷰포트 대응)

**날짜:** 2026-08-14
**작업:** Wave 1.6 item 8 — 팝업 뷰포트 안전성 강화
**변경 파일:** `popup.css`

## 변경 내용

### 문제점
- `body { width: 340px; }` — 고정 너비로 200% 줌 시 뷰포트 초과 발생
- `.shell { max-height: 520px; }` — 고정 높이 값, 동적 뷰포트 미지원
- `html`에 오버플로우 숨김 부재로 수평 스크롤 가능성
- 존재하지 않는 `.popup-root` 요소에 대한 죽은 CSS 미디어 쿼리 (lines 492-496)

### 수정 사항

1. **body 너비:** `width: 340px` → `width: min(340px, 100vw)` + `max-width: 100vw`
2. **html 오버플로우:** `html { overflow: hidden; }` 추가
3. **body 수평 보호:** `overflow-x: hidden` 추가
4. **.shell 높이:** progressive cascade — `max-height: 520px` → `min(520px, 100vh)` (폴백) → `min(520px, 100dvh)` (지원 브라우저)
5. **.shell 수평 보호:** `overflow-x: hidden` 추가
6. **죽은 CSS 제거:** `.popup-root` 미디어 쿼리 완전 삭제

## 발견 사항

- `popup.html`의 실제 루트 구조: `body > main.shell` (`.popup-root` 없음)
- `100dvh`는 대부분의 최신 브라우저에서 동적 뷰포트(주소 표시줄 포함/제외를 자동으로 조정)를 지원
- `100vh` 폴백으로 레거시 브라우저 대응 가능
- `.shell` height 계약: large desktop에서 520px ceiling 유지, narrow/zoomed 뷰포트에서 `min(520px, 100vh/100dvh)`로 동적 조정
- cascade 순서: `520px` (데스크톱 원본 계약) → `min(520px, 100vh)` (비-dvh 브라우저 폴백) → `min(520px, 100dvh)` (지원 브라우저 최종)
