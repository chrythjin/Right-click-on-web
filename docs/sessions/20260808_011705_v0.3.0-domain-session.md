## 2. Changes

### 신규 파일
- `shared.js` — `RIGHT_CLICK_ON_WEB_SHARED` 전역 객체. PUBLIC_SUFFIX_BLOCKLIST (~40개 멀티파트 TLD), MAX_DOMAIN_MATCH_DEPTH=5, STORAGE_DEFAULTS, SESSION_KEY_PREFIX, sessionKeyFor, getHostname, resolveDomainKey, isDomainEnabled, storageGet/Set/Remove Promise wrappers, isSessionStorageAvailable. 세 컨텍스트(content.js, popup.js, background.js)에서 공통 사용.

### manifest.json
- `activeTab` 권한 추가 — 팝업에서 `chrome.tabs.query({active: true, currentWindow: true})`로 현재 탭 hostname 조회용.
- `content_scripts[0].js`를 `["shared.js", "content.js"]`로 변경 — shared.js가 content.js보다 먼저 로드되도록.

### background.js
- `importScripts('shared.js')`로 shared 헬퍼 로드.
- DEFAULT_SETTINGS를 `{enabled: true}` → `{enabled: true, domainSettings: {}}`로 확장.
- `initializeStorage()` 함수 신설 — 기존 enabled 값을 보존하면서 domainSettings 누락 시에만 {}로 채움. pre-v0.3.0 사용자 데이터 자동 마이그레이션.
- `chrome.runtime.onStartup`에 동일 초기화 추가 — 사용자가 chrome://extensions에서 데이터를 삭제한 경우에 대비.

### content.js
- `async resolveEnabled()` 신설 — session > domain > global 우선순위로 enabled 결정. 반환: `{enabled, source, hostname, matchedKey}`. source ∈ {'session', 'domain', 'global', 'global-no-host'}.
- `resolveAndApply()` 신설 — race-condition 가드. 모듈 레벨 `resolvePromise` 싱글톤으로 동시 onChanged 호출을 단일 in-flight promise로 coalesce.
- `chrome.storage.onChanged` 리스너 확장 — local(enabled/domainSettings)과 session(모든 키) 모두 감지. content.js가 session area도 듣는 이유는 popup이 쓴 `session:<hostname>` 키 변경을 실시간 반영하기 위함.
- `createStats()`에 v0.3.0 진단 필드 추가 — `resolveSource`, `matchedDomain`. resolveAndApply가 매 결정마다 stats 객체에 surface.
- `lastResolveSource`, `lastMatchedDomain` 모듈 변수(중복 캐시)는 첫 코드 리뷰에서 발견하여 제거 — stats 객체로 일원화.

### popup.html
- `<script src="shared.js">` 추가 (popup.js보다 먼저).
- status-card 아래에 `<section class="domain-card">` 추가 — "현재 사이트" 라벨, hostname 표시, 도메인 토글 버튼, hint 문구.
- domain-card 아래에 `<button class="session-button">` 추가 — "이번 세션만 임시 활성화" / 활성 시 "세션 활성화 중 — 클릭하여 끄기".
- 하단 notice 문구 보강 — "OFF로 전환 후에도 MAIN world 패치는 새로고침 전까지 유지됩니다."

### popup.css
- `--muted-soft: #9a9a9a` 변수 추가 — hint, 비활성 hostname에 사용.
- `.domain-card`, `.domain-card-text`, `.domain-text`, `.domain-hint`, `.domain-hint.is-domain-off`, `.toggle-small` 스타일 추가.
- `.session-button`, `.session-button:hover`, `.session-button.is-active` 스타일 추가 — 점선→실선 border 변화 + ✓ pseudo-element.
- `.toggle-button:disabled` 스타일 추가 — disabled 상태에서 transform/opacity 처리.
- `.shell { max-height: 520px; overflow-y: auto }` 추가 — 도메인 카드/세션 버튼 추가로 인한 세로 스크롤 대비.
- `prefers-reduced-motion` 미디어 쿼리에 `.session-button`도 추가.

### popup.js
- `state` 객체로 모든 UI 상태 통합 — globalEnabled, hostname, domainSettings, domainEntry, sessionActive, effectiveEnabled.
- `getCurrentHostname()` 신설 — `chrome.tabs.query` + `SHARED.getHostname`. 비-http(s) 페이지에서는 '' 반환하여 도메인 컨트롤 비활성.
- `loadState()` — chrome.storage.local에서 enabled+domainSettings 읽고, hostname 있으면 session에서도 읽음. 예외 발생 시 안전한 기본값으로 fallback.
- `render()` — global/domain/session 3개 컨트롤 + hint 동기 갱신. hostname이 ''이면 도메인/세션 컨트롤 disabled.
- `handleGlobalToggle()`, `handleDomainToggle()`, `handleSessionToggle()` — 각 레이어별 단일 책임 쓰기 핸들러.
- 도메인 토글은 현재 사이트의 "session 무시한" 상태(`domainDecisionIgnoringSession`)를 기준으로 반전. 즉 global=OFF+domain=null일 때 클릭 → domain entry=true (사이트만 ON).
- `chrome.storage.onChanged` 리스너 — local(enabled/domainSettings)과 session(모든 키) 변경 시 loadState+render 재실행.

- 섹션 9 hostname 표시는 inline `<script>`에서 window.location.hostname으로 채움.

## 3. Before / After

### Before (v0.2.0)
- 전역 ON/OFF 단일 토글만 지원. `chrome.storage.local.enabled` boolean 하나.
- 도메인별 제어: 없음.
- 세션 모드: 없음.
- shared 헬퍼: 없음 — 각 파일이 자체 DEFAULT_SETTINGS 선언, 단일 키만 다룸.
- popup UI: status-card 1개 + feature-list. 약 60px 세로 높이.

### After (v0.3.0-alpha)
- 3-레이어 우선순위 판정: session > domain > global.
- 도메인별 ON/OFF: popup에서 현재 사이트 토글. subdomain 자동 매칭 (www.example.com → example.com). public suffix 우회 (co.uk 등록 시 .co.uk 사이트 전체 차단 안 됨).
- 세션 모드: popup에서 현재 사이트 한시적 활성화. chrome.storage.session 사용, 탭 닫거나 브라우저 종료 시 자동 소멸.
- shared.js 단일 진실 공급원 — 3개 컨텍스트가 동일 헬퍼 사용. resolveDomainKey 진리표 6케이스 명시.
- popup UI: status-card + domain-card + session-button + feature-list + notice. 세로 스크롤 가능.

## 6. 검증 필요 항목 (수동 테스트)

1. **domain ON 후 OFF 토글**: 확장 ON 상태 → popup에서 도메인 OFF → 페이지 우클릭 시 컨텍스트 메뉴 안 떠야 함
2. **subdomain 매칭**: www.example.com에서 example.com 도메인 설정이 자동 적용되는지
3. **public suffix 우회**: shop.example.co.uk에서 co.uk 도메인 OFF 설정이 무시되는지
4. **세션 우선순위**: global OFF + domain OFF 상태에서 세션 ON → 페이지 우클릭 풀림
5. **세션 만료**: 탭 새로고침 또는 닫기 후 chrome.storage.session 키가 살아있는지 (수동 확인, content.js는 같은 키를 다시 읽음)
6. **iframe hostname**: 다른 도메인 iframe의 content.js는 각자의 hostname으로 독립 결정
7. **chrome:// 페이지**: popup에서 "이 페이지에서는 도메인 설정 불가" 표시 + 도메인/세션 버튼 disabled
8. **storage.onChanged coalescing**: popup에서 빠르게 global OFF + domain OFF → content.js가 두 변경을 한 번에 처리
