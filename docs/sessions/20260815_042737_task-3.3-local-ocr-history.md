# 작업 3.3 선택형 로컬 OCR 기록

## 목적

성공한 OCR 결과의 사용자가 최종 편집한 텍스트만 명시적 요청에 따라 이 기기에 보관한다. 기록은 기본 OFF이며, OCR 원본, 이미지, 캡처 바이트, URL 경로와 쿼리, 클립보드, 임의 메타데이터를 저장하거나 Chrome Sync로 전송하지 않는다.

## 구현

- `ocr-history.js` UMD 제품 helper가 허용된 `{ id, text, hostname, savedAt }` 형태만 새 객체로 정규화한다. 텍스트는 12,000자, hostname은 253자, ID는 48자로 제한한다.
- retention은 최신순으로 20개, 30일 TTL, UTF-8 JSON 바이트 64KiB를 모두 적용한다. malformed 또는 중복 ID legacy entry는 읽기 시 제거한다.
- `background.js`는 `chrome.storage.local`에서만 history 상태와 entry를 처리한다. install/default 초기화는 `ocrHistory` 키를 만들지 않으며, 마지막 entry 삭제와 disable+delete는 키 자체를 `remove()`한다.
- 모든 OCR 기록 mutation(save, 개별 삭제, 전체 삭제, enable/disable)과 cleanup persistence가 가능한 공개 조회는 하나의 recoverable promise-tail critical section을 공유한다. `readOcrHistorySnapshot()`은 queued callback 안에서만 쓰는 unqueued snapshot/cleanup helper이고, public `getOcrHistory()`가 이를 enqueue한다. later 호출이 deterministic winner이며 recursive wait가 생기지 않는다.
- options/side-panel은 Korean-first opt-in toggle, 현재 편집본 저장, local text/hostname search, 개별 삭제, 전체 삭제, 끄고 삭제를 제공한다. history-only write failure는 OCR session result를 바꾸지 않고 기록 상태 영역에만 표시한다.
- `ocrHistoryStatus`만 기록 변경을 live announcement로 사용해 검색/렌더링 때 항목 전체가 중복 발표되지 않도록 했다.
- provenance 수정: `ocrDisplayedResult`가 textarea의 현재 accepted 결과를 가리킨다. dirty 편집 중 새 `latestOcrResult`가 pending으로 도착해도 기록 저장은 기존 표시 결과의 hostname을 사용하며, 사용자가 새 결과를 수락할 때만 text와 provenance를 함께 새 결과로 교체한다.

## 검증

- `node --test tests/unit/options-profile-ui.test.js tests/unit/ocr-history.test.js tests/unit/toolbar-action-background.test.js`: 81개 통과, 0개 실패. provenance 회귀는 dirty A 편집본과 pending B 결과에서 A hostname을 저장하고, B 수락 뒤 B 편집본과 B hostname을 저장함을 실제 `options.js` 함수 VM 경로로 검증한다. 또한 delayed save 뒤 individual delete, delete-all, disable+delete가 later mutation으로 승리하고 실패 뒤 다음 mutation이 실행됨을 실제 background VM storage path로 검증한다. 만료 entry cleanup write-back을 강제한 public get도 이후 save, delete-all, individual delete를 덮어쓰거나 되살리지 않으며 cleanup write 실패 뒤 다음 save가 실행됨을 검증한다.
- `$files = @(Get-ChildItem -LiteralPath 'tests/unit' -Filter '*.test.js' | Sort-Object -Property Name | ForEach-Object { $_.FullName }); node --test $files`: 291개 통과, 0개 실패.
- `node --check background.js; node --check ocr-history.js; node --check options.js; node --check tests/unit/ocr-history.test.js; node --check tests/unit/toolbar-action-background.test.js`: 통과.
