# v0.6.3 배포 패키지 준비

**일시:** 2026-08-12 08:21
**대상 릴리스:** v0.6.3

## 배포 내용

- 확장 활성화 시 정상 왼쪽·가운데 클릭과 터치 입력 사슬이 차단될 수 있던 v0.6.2 회귀를 수정했다.
- `mousedown`과 `mouseup` 인터셉터는 오른쪽 버튼 입력에만 적용한다.
- `onmousedown`, `onmouseup`, 전역 `touch*` 인터셉터를 제거해 정상 사이트 상호작용을 보존한다.
- 수동 QA 페이지에 `mousedown → mouseup → click` 전달 시나리오를 추가했다.
- `manifest.json` 버전을 `0.6.3`으로 올렸다.

## 검증

- ZIP 내부 manifest가 Manifest V3, 버전 `0.6.3`임을 확인했다.
- ZIP의 13개 파일을 작업 트리 원본과 SHA-256으로 각각 비교해 모두 일치함을 확인했다.
- 필수 파일 누락과 허용 목록 외 파일이 없음을 확인했다.
- 배포 JavaScript 6개 모두 `node --check`를 통과했다.
- `ocr review`는 변경된 소스와 manifest에서 결함을 보고하지 않았다.
- 일반 클릭 회귀 수정은 브라우저 QA 하니스와 이벤트 경계 드라이버에서 왼쪽·가운데 입력 전달 및 오른쪽 입력 차단을 확인했다.
