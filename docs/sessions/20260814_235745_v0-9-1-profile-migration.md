# v0.9.1 feature profile 정규화와 마이그레이션

## 작업 범위

- `shared.js`에 feature profile preset 상수, feature key allowlist, 기본 및 preset별 전체 feature map을 추가했다.
- legacy domain setting과 새 profile 입력을 하나의 `parseDomainSetting()`/`normalizeDomainSettings()` 정본으로 정규화했다.
- `background.js` update migration이 sync/local을 모두 처리하고 이미 정규화된 값에는 write하지 않도록 했다.
- 실제 제품 함수를 로드하는 Node/VM 단위 테스트에 요구 입력 행렬과 migration 멱등성 검증을 추가했다.

## API 계약

- 브라우저의 `RIGHT_CLICK_ON_WEB_SHARED`는 `safe`, `selection`, `complete`, `upload-safe`, `media-safe`, `custom` preset과 9개 feature의 canonical snapshot을 공개한다.
- Node `require('./shared.js')`는 기존 계약대로 `parseDomainSetting`, `normalizeDomainSettings` 두 함수만 export한다.
- boolean 및 `{ enabled }`는 Ultimate/complete feature로 확장되고, `{ enabled, mode:'lite' }`는 기존 Lite 의미를 보존하는 custom profile(`ultimateCss:false`)로 확장된다.
- 알려진 preset은 전달된 feature 값을 신뢰하지 않고 canonical 전체 snapshot으로 만든다. custom은 own allowlisted boolean만 받아 누락 값을 기본 map으로 채운다.
- invalid string, `null`, array, non-plain object는 disabled complete 기본값으로 안전하게 정규화된다.

## 저장소 마이그레이션

- update 시 local-to-sync 선행 정책은 유지하고 이후 sync/local domainSettings를 각각 정규화한다.
- 각 저장소는 domainSettings whole object를 교체하며 sync/local merge 및 fallback marker 정책을 변경하지 않는다.
- 정규화 전후 JSON 구조가 같으면 write하지 않는다. VM 테스트에서 첫 실행은 sync/local 각각 1회, 두 번째 실행은 0회 추가 write를 확인했다.

## 검증

- `node --test tests/unit/*.test.js`: 114개 통과.
- `node --check shared.js`, `background.js`, 변경 unit test 2개: 통과.
- `& .\scripts\verify.ps1 -RootPath (Get-Location)`: 통과.
- 변경 파일 built-in diagnostics: 오류 없음.
- `agent-lsp_blast_radius`: LSP client 미초기화로 실행 불가. codegraph caller 분석과 위 정적/동적 검사로 대체했다.

실제 unpacked Chrome update migration은 승인된 브라우저 대상이 없어 수행하지 않았으며 v0.9.0 release/manual QA 통과를 주장하지 않는다.

## 검증 retry: plain object 판별

- 최초 구현의 `Object.getPrototypeOf(prototype) === null` 조건은 custom class instance의 prototype chain도 허용하는 결함이 있었다.
- 수정된 guard는 null-prototype object를 직접 허용하고, 그 외에는 prototype 자체가 root prototype이며 own `constructor`의 native 함수 소스가 해당 realm의 `Object`와 일치할 때만 ordinary object로 승인한다.
- same-realm 및 VM cross-realm ordinary/null-prototype object는 계속 승인하고, same-realm 및 VM cross-realm class instance와 `Date`는 disabled complete로 정규화하는 제품 함수 테스트를 추가했다.
- retry 검증은 `node --test tests/unit/settings-characterization.test.js` 10개, 전체 `node --test tests/unit/*.test.js` 114개, `node --check shared.js`, repository verifier를 모두 통과했다.
