# v0.10.0 자동 릴리스 게이트

## 목적

작업 3.1~3.5의 구현 결과를 대상으로 v0.10.0 자동 검증, 패키지 closure, ZIP과 현재 소스의 byte-level 일치, 런타임 원격 참조 부재를 확인한다. 이 기록은 작업 3.6의 계획 체크박스를 변경하지 않으며, unpacked Chrome 수동 QA가 남아 있어 작업 전체 완료를 주장하지 않는다.

## 패키지와 소스 정합성

- `manifest.json`의 출시 버전을 `0.8.0`에서 `0.10.0`으로 정정했다. v0.10.0 패키지 파일명 및 `AGENTS.md`/배포 매뉴얼의 정본 allowlist와 일치시킨 유일한 제품 구성 변경이다.
- `Compress-Archive`에는 문서화된 24개 root allowlist 항목만 전달했다. 결과 `right-click-on-web-v0.10.0.zip`에는 제품 파일 29개가 들어 있으며, `docs/`, `tests/`, `history/`, `.git/`, `.omo/`, `assets/`, `popup-preview.html`, 기존 ZIP은 포함되지 않았다.
- ZIP의 모든 29개 파일을 현재 작업 트리의 같은 상대 경로 파일과 SHA-256으로 대조했다. 불일치는 0개였다.
- ZIP 크기는 `6,188,707` bytes, ZIP 자체 SHA-256은 `9F09F84513EAFD7C51167677966632D00C2825CE29CBBE82394C05E2ECF6AFD5`이다.

## 자동 검증

- `node --test tests/unit/*.test.js`: 294개 통과, 실패 0개.
- `node --check`를 제품 JavaScript 19개 파일에 실행: 통과.
- `& .\scripts\verify.ps1 -RootPath (Get-Location)`: JavaScript syntax, manifest JSON parse, MAIN-first content script ordering, MAIN blocked-event allowlist, 제품/OCR asset, background helper ordering, local-only offscreen script, `git diff --check` 모두 통과.
- 별도 `git diff --check`: exit 0. 출력된 LF-to-CRLF 안내는 기존 dirty worktree 경고이며 파일 정규화는 수행하지 않았다.
- 제품 런타임 파일 대상으로 원격 script/network reference 정적 검색을 실행했다. 유일한 `https://` 매치는 `shared.js`의 Chrome storage API 출처 주석이며 실행 코드가 아니다. `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource` 매치는 없었다. 문서 URL은 검색 범위에서 제외해 제품 런타임 참조와 구분했다. verifier의 `offscreen.html uses only local OCR scripts` 검사도 통과했다.

## 작업 3.6 자동 행렬 근거

- visible rect/DPR/stale TTL/viewport mismatch: `tests/unit/image-context.test.js`, `tests/unit/ocr-image-utils.test.js`, `tests/unit/ocr-session-utils.test.js`의 nested frame clipping, DPR scaling, cache stale timestamp, rerun viewport/DPR/TTL rejection 테스트가 통과했다.
- OCR history bounds/default-OFF/malformed: `tests/unit/ocr-history.test.js`의 allowlist, count/TTL/byte cap, local-only default-OFF 검사가 통과했다.
- image URL non-storage: `tests/unit/image-context.test.js` 및 `tests/unit/ocr-session-utils.test.js`의 image URL/cache/rerun allowlist 검사가 통과했다.
- manifest ordering: `tests/unit/image-context.test.js`와 `scripts/verify.ps1`의 MAIN-first 및 image observer ordering 검사가 통과했다.

## 수동 QA 차단 상태

- 실제 unpacked Chrome 수동 QA는 수행하지 않았다. `chrome-devtools` MCP 서버가 등록되어 있지 않고, Playwright 현재 대상은 `about:blank`이며 이 확장은 로드되어 있지 않다.
- 따라서 이미지 OCR, iframe fallback, high-DPI, 기록 opt-in/out, 마지막 영역 repeat의 브라우저 관찰은 승인·연결된 unpacked Chrome target이 제공될 때까지 별도 릴리스 게이트로 남는다.

## 도구 제한

- `agent-lsp` blast radius는 `LSP client not initialized`로 실행할 수 없었고, `lsp_diagnostics`는 Biome 서버가 설치되지 않아 실행할 수 없었다. 기존 저장소 제약에 따라 Node unit tests, Node syntax check, repository verifier, ZIP hash 비교로 대체했다.
