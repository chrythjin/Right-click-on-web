Manual blocked page

확장 ON 상태에서 아래 영역의 우클릭, 선택, 복사, 드래그, 모바일 길게 누르기를 테스트하세요.

확장 실행 통계 (window.__rightClickOnWebStats): 
통계 데이터 없음

1. 기본 차단 (우클릭 / 선택 / 복사 / 드래그)

이 섹션의 본문 텍스트는 페이지 CSS(user-select: none)와 인라인 이벤트로 차단됩니다. 확장 ON 시 우클릭/선택/복사/드래그가 풀려야 합니다.

이 문장은 페이지 CSS와 inline event attribute로 선택/복사/우클릭이 막히도록 구성된 테스트 텍스트입니다.

2. 이미지 드래그 저장 (user-drag: none)

이 이미지는 -webkit-user-drag: none; user-drag: none; CSS로 데스크탑 드래그 저장이 차단됩니다. 확장 ON 시 이미지를 드래그해 데스크탑에 저장할 수 있어야 합니다.

3. 텍스트 드롭 영역 (dragover / drop)

아래 드롭 영역은 인라인 ondragover, ondrop으로 텍스트 드롭을 차단합니다. 확장 ON 시 외부에서 선택한 텍스트를 이 영역에 드롭할 수 있어야 합니다.

여기로 텍스트를 드롭하세요. 드롭 시 페이지 측 경고가 나타나지 않고 정상적으로 텍스트가 떨어져야 합니다.

4. 차단 오버레이 (pointer-events 무력화)

아래 영역에는 페이지가 우클릭 차단을 위해 깔아둔 투명 오버레이 div가 있습니다. 확장 ON 시 오버레이가 무력화되어 아래 본문 텍스트를 우클릭/드래그할 수 있어야 합니다.

오버레이 아래 본문 텍스트입니다. 여기 우클릭/드래그 가능해야 합니다.

5. 모바일 터치 차단 (touchstart 등)

모바일 Chrome에서 이미지/링크를 길게 누를 때 컨텍스트 메뉴(이미지 저장/링크 복사)가 차단됩니다. 이 영역은 인라인 ontouchstart로 차단됩니다. 모바일 실기기/모바일 에뮬레이션으로 테스트하세요.

6. 사후 등록 리스너 차단 (addEventListener 패치)

아래 버튼을 누른 뒤 영역을 우클릭해도 페이지의 차단 리스너(preventDefault)가 동작하지 않아야 합니다. MAIN world 프로토타입 패치(content-main.js)가 사후에 등록되는 차단 리스너를 자동으로 무력화합니다.

상태: 미등록

이 영역을 우클릭하여 브라우저 컨텍스트 메뉴가 열리는지 확인하세요.

7. 주기적 재스캔 및 Shadow DOM 재귀

아래 버튼을 누르면 setInterval로 0.5초마다 차단 속성을 다시 부착합니다. 확장 ON 상태에서도 차단이 풀린 상태가 유지되어야 합니다. 통계 패널의 periodicRescans 카운터가 증가하는지 확인하세요.

상태: 중지됨

이 영역에서 우클릭/복사 차단이 풀린 상태로 유지되는지 확인하세요.

8. Closed Shadow DOM 강제 변환

아래 버튼을 누르면 사용자 정의 요소가 attachShadow({mode:'closed'})를 호출하고, Shadow Root 내부에서 인라인 on* 속성, addEventListener, user-select: none으로 우클릭·복사·선택을 차단합니다. 확장 ON 상태에서는 MAIN world 패치가 closed를 open으로 변환하고 content.js가 내부 차단을 정리합니다. Ultimate에서는 Shadow Root 내부 텍스트도 선택 가능해야 합니다.

9. 도메인별 ON/OFF (v0.3.0)

이 페이지의 hostname은 - 입니다. 확장 아이콘을 클릭하여 현재 사이트 토글을 OFF로 변경한 뒤, 아래 영역을 우클릭/복사해 보세요. 도메인 OFF가 적용되면 차단이 풀리지 않아야 합니다. "실행 통계 보기" 패널의 resolveSource가 "domain", matchedDomain이 현재 hostname인지 확인하세요.

  1. 확장 팝업 열기 → "현재 사이트" 카드에서 도메인 토글 OFF 클릭
  2. 아래 영역 우클릭 → 컨텍스트 메뉴가 뜨지 않아야 함 (도메인 OFF 적용)
  3. 다시 도메인 토글 ON 클릭 → 컨텍스트 메뉴 다시 정상
이 영역을 우클릭/복사 시도하여 도메인 토글 효과를 확인하세요.

10. 세션 임시 활성화 (v0.3.0)

전역 OFF + 도메인 OFF 상태에서도, 확장 팝업의 "이번 세션만 임시 활성화" 버튼을 누르면 이 페이지에서만 우클릭 차단이 풀립니다. 새로고침이나 탭을 닫았다 다시 열어도 현재 브라우저 세션 동안 유지되며, 브라우저를 완전히 종료하면 자동으로 해제됩니다 (chrome.storage.session 특성).

  1. 전역 토글 OFF
  2. 시나리오 9에서 도메인 토글 OFF
  3. 이 영역 우클릭 → 차단 (어떤 레이어도 ON이 아님)
  4. 팝업에서 "이번 세션만 임시 활성화" 클릭
  5. 이 영역 우클릭 → 풀림 (세션 레이어 우선)
  6. 새로고침 → 세션 설정은 유지되어 계속 풀림 (브라우저 세션 종료 후 자동 해제)
이 영역에서 우클릭/복사를 시도하여 세션 모드 효과를 확인하세요.

11. Lite / Ultimate 모드 (v0.5.0)

Ultimate는 CSS user-select 주입까지 모두 적용 (기본). Lite는 MAIN world 패치와 capture-phase 인터셉터만 적용 — 페이지의 user-select 스타일은 보존되지만 우클릭·복사·드래그 차단은 여전히 풀립니다.

  1. 확장 팝업 → 현재 사이트에서 도메인 ON
  2. 모드 선택에서 "Lite" 클릭
  3. 아래 영역 우클릭 → 컨텍스트 메뉴 정상 (Lite도 작동)
  4. 아래 텍스트 선택 시도 → 페이지의 user-select: none이 살아있으면 선택 불가 (Lite의 차이점)
  5. 팝업에서 "Ultimate" 클릭 후 다시 시도 → 선택 가능 (CSS 주입 복원)
이 영역은 Lite 모드에서 user-select: none이 적용되어 선택이 차단됩니다. Ultimate로 전환하면 풀립니다.

실행 통계의 mode 필드가 현재 적용 모드("lite" 또는 "ultimate")를 표시합니다.
